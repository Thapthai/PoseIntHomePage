# ผลตรวจชุดส่งงาน

ตรวจเมื่อ 15 กันยายน 2026

- Build สำเนาส่งงานด้วย `vinext build`: ผ่าน (exit code 0)
- Build แสดง route หน้าเว็บเพียง `/` ไม่รวมหน้า Healthcare ที่สร้างขึ้นใหม่
- การทดสอบ build ใช้ dependency ที่ติดตั้งอยู่แล้วในเครื่องเดิม ผ่านลิงก์ชั่วคราว ไม่ใช่การทดสอบติดตั้งใหม่จาก registry บนเครื่องเปล่า
- ไม่รวมลิงก์ dependency, `node_modules`, ผล build หรือไฟล์แคชใน ZIP ส่งงาน ผู้รับต้องติดตั้ง dependency เอง
- เมนู Healthcare ของสำเนาชี้ไป `https://poseintelligence.com/` ตามขอบเขตที่เจ้าของงานระบุ
- Thai hero: “เปลี่ยนผ้าทุกชิ้น” / “ให้มีตัวตน”; สัญลักษณ์หลัง “ชิ้น”
- English hero: “Track Every Linen for Smarter Management”; สัญลักษณ์หลัง “Smarter”
- ไม่ได้แก้ไขต้นฉบับใน `pose-intelligence-site` หรือเผยแพร่เปลี่ยนเว็บไซต์ออนไลน์ระหว่างจัดชุดส่งงาน
- ไม่ได้ตรวจหน้าจอซ้ำบนเบราว์เซอร์ทุกอุปกรณ์หรือทดสอบบนโฮสต์ของผู้รับ ต้องทำก่อนเปิดใช้จริง
- ไม่ได้แนบหรือย้ายโค้ดต้นฉบับของเว็บไซต์โรงพยาบาลเดิม

Vinext แสดงคำเตือนว่าบาง route ไม่สามารถจัดประเภทด้วย static analysis ได้ แต่ build เสร็จสำเร็จ ไม่ควรนำไปตีความว่าได้ทดสอบ runtime บนโฮสต์ปลายทางแล้ว
